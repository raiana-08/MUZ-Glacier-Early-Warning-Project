# MUZ-Glacier-Early-Warning-Project

MUZ | LSE Global Innovation Challenge

Focus: Glacier-related hazards in Kyrgyzstan.

Research: Community vulnerability, disaster risks, and early-warning systems.

Goal: Explore accessible solutions, including mobile alerts and sirens, to improve community safety and disaster preparedness.
